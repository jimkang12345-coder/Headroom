# Contributing

Keep all app features free and keep private processing local. Explain each connection's authentication, destinations, metric semantics, refresh and deletion behavior before adding it.

Run the core tests and Mac build for affected behavior. Add focused tests for security boundaries and error paths. Record commands/results honestly; historical success is not current verification. For a visible change, capture only a reviewed fixture/demo app window and label its data mode. Never include real account information in screenshots.

Before committing, review the exact staged file list and content. Exclude local journals, exports, credentials, sessions, signing files, personal paths and raw logs. Keep additional dependencies small and explain why they are needed. Themes and widget templates must contain appearance settings only, with no executable code or account observations.
